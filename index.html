Part 2: Structuring with HTML

HTML (HyperText Markup Language) is not a programming language; it's a markup language.

Anatomy of an HTML Element

HTML의 유일한 목적은 '태그'를 사용해 콘텐츠를 설명하고 구조화하는 것입니다.

<p class="intro">
  이것이 콘텐츠입니다.
</p>
  • Opening Tag: <p> - 요소의 시작을 알립니다.
  • Content: 요소가 설명하는 실제 내용입니다.
  • Closing Tag: </p> - 요소의 끝을 알립니다.
  • Attribute: class="intro" - 태그에 추가 정보를 제공합니다.

HTML as a Data Structure: The DOM

HTML을 단순한 텍스트가 아닌, 브라우저가 파싱하여 만드는 **데이터 구조(DOM Tree)**로 이해하는 것이 중요합니다.

여러분이 작성하는 모든 태그는 DOM 트리의 '노드(Node)'가 됩니다. 이 구조적 관점은 CSS와 JavaScript 작업의 기반이 됩니다.

Analogy for Python Devs

Think of HTML as the source code for creating a nested data structure, like a tree of objects, that the browser holds in memory.

Essential HTML Tags

These are the fundamental building blocks for any webpage.

TagNameDescriptionType
<h1>-<h6> Heading 문서의 제목을 계층적으로 나타냅니다. h1이 가장 중요합니다. Block
<p> Paragraph 텍스트의 한 문단을 정의합니다. Block
<a> Anchor (Link) 다른 페이지로 연결되는 하이퍼링크를 만듭니다. (href 속성) Inline
<img> Image 웹페이지에 이미지를 삽입합니다. (src, alt 속성) Inline
<div> Division 여러 요소를 그룹화하는 범용 블록 레벨 컨테이너입니다. (레이아웃의 핵심) Block
<ul> / <li> List ul(순서 없는 목록)과 li(목록 항목)를 정의합니다. Block
<span> Span 텍스트의 일부를 그룹화하는 범용 인라인 컨테이너입니다. Inline
Block 요소는 전체 너비를 차지하고 새 줄에서 시작하며, Inline 요소는 콘텐츠 크기만큼만 차지하고 줄바꿈 없이 배치됩니다.

Part 3: Styling with CSS

CSS (Cascading Style Sheets) is the language for describing the presentation of a webpage.

Anatomy of a CSS Rule

CSS는 '선택자'와 '선언'으로 구성된 간단한 문법을 가집니다.

.profile-card {
  background-color: white;
  padding: 20px;
}
  • Selector: .profile-card - 스타일을 적용할 HTML 요소를 지정합니다.
  • Declaration Block: {...} - 하나 이상의 선언을 포함합니다.
  • Property: background-color - 바꾸고 싶은 스타일 속성입니다.
  • Value: white - 속성에 적용할 값입니다.

The "Cascade" and Separation

Separation of Concerns: 스타일(CSS)을 구조(HTML)와 분리하는 것은 재사용성과 유지보수성의 핵심입니다. 100개 버튼의 색상을 한번에 바꿀 수 있습니다.

Cascading: 스타일은 폭포수처럼 위에서 아래로 적용되며, 여러 규칙이 충돌할 경우 더 '구체적인(specific)' 규칙이 우선순위를 가집니다.

Specificity Hierarchy (High to Low)

Inline Styles > ID (#id) > Class (.class) > Tag (p)

The Box Model: The #1 CSS Concept

Every element in HTML is a rectangular box. Understanding its parts is key to layout.

Margin (바깥 여백)

Border (테두리)

Padding (안쪽 여백)

Content

Content: 실제 텍스트나 이미지가 들어가는 영역.

Padding: 테두리 안쪽의 여백. 콘텐츠와 테두리 사이의 공간.

Border: 패딩과 콘텐츠를 감싸는 선.

Margin: 테두리 바깥쪽의 여백. 다른 요소를 밀어내는 공간.

Part 4: Interacting with JavaScript

JavaScript is a full programming language that runs in the browser. It brings your page to life.

Familiar Concepts

파이썬처럼 변수, 자료형, 함수, 반복문, 조건문을 모두 가지고 있습니다. 문법은 다르지만, 기본 개념은 동일합니다.

Python vs. JavaScript

If you can write def my_func(): in Python, you can write function myFunc() {} in JavaScript. You are not starting from scratch!

The Core Mission

JavaScript의 주된 임무는 브라우저 내에서 다음 두 가지를 수행하는 것입니다.

  • React to user events: Clicks, mouse movements, keyboard input, etc.
  • Manipulate the DOM: Dynamically change the HTML and CSS of the page.

The Fundamental JavaScript Pattern

Nearly all simple frontend interactions follow this 3-step mental recipe.

1

SELECT

조작하고 싶은 HTML 요소를 선택하여 변수에 저장합니다.

const button = document.querySelector('#my-btn');

2

LISTEN

선택한 요소에서 특정 '이벤트'가 발생하는 것을 감지합니다.

button.addEventListener('click', ...);

3

MANIPULATE

이벤트가 발생했을 때 실행할 함수를 통해 DOM을 조작합니다.

() => { heading.textContent = 'New text!'; }

This "Select, Listen, Manipulate" pattern is your roadmap for making things happen on a webpage.

Syntax Side-by-Side: Python vs. JavaScript

The concepts are the same, just with different punctuation.
